# Accessibility

Voyager Access exists to make Star Trek: Voyager - Across the Unknown playable without sight. Accessibility is the whole point of the project, not a feature of it, so a screen that is silent or a key that does nothing is a bug, and we want to hear about it.

## Who it is for

Voyager Access is built by a blind player for blind and low-vision players who use a screen reader. It is developed and played every day with NVDA and JAWS.

## What it supports

- Speech through NVDA or JAWS. If neither is running, Windows' own speech is used instead.
- The keyboard for everything Voyager Access covers, including things the game only offers with a mouse or a controller, such as building rooms and giving orders in battle. Press F1 in the game to hear the keys for the screen you are on, or Control+F1 for every key.
- Windows 11 (64-bit), the system Steam lists for the game, with the full game or the free Steam demo.

The whole free demo has been played through to its end with Voyager Access, and it works with the full game too. The full game is larger than the demo, so expect a few gaps there.

## Known limits

- A game update can move or rename things the mod reads. When that happens, part of a screen can go silent until Voyager Access is updated. Voyager Access updates itself, so the fix reaches you the next time you start the game after a new version is out.
- Voyager Access is unofficial. It cannot change how the game itself is made; it reads what the game shows and adds keys of its own.

## Reporting a problem

If something is silent, wrong, or a key does nothing:

1. Press the Backtick key (the key left of 1) in the game. It copies a troubleshooting report to the clipboard. If speech has stopped altogether, use "Copy a troubleshooting report" in the Start menu's Voyager Access folder instead; it works without the game.
2. [Open an issue on this repository](https://github.com/csm120/VoyagerAccess/issues/new) and paste the report. Say which screen reader you use and its version, which screen you were on, what you pressed, and what happened instead.

If you would rather not post publicly, email help@webfriendlyhelp.com with the same details.

## Contributing

Changes have to keep every screen keyboard-operable and spoken correctly with NVDA and JAWS. Every new screen follows the [Voyager Access keyboard rules](docs/keyboard.md), and nothing is ever described by its color.
